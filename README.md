# Abstraction-Automation-System
This project demonstrates the concept of Abstraction in Python using the `abc` module.

An abstract class named `BuildingSystem` defines three abstract methods:

- start()
- stop()
- status()

Four child classes inherit from the abstract class:

- AirConditioningSystem
- LightingSystem
- SecuritySystem
- FireAlarmSystem

Each class implements all abstract methods.

Objects of the classes are stored in a list, and polymorphism is demonstrated by calling the same methods on each object through a single processing loop.

## Concepts Demonstrated
- Abstraction
- Abstract Classes
- Abstract Methods
- Inheritance
- Method Overriding
- Polymorphism
